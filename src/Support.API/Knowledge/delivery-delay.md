# Вопрос о задержке доставки
Покупатель может создать заявку в поддержку по своему заказу, если хочет уточнить срок доставки.
Для записи заявки требуется явное разрешение покупателя.
Поддержка уточняет обстоятельства и срок у службы доставки. Создание заявки само по себе не одобряет компенсацию, отмену заказа или возврат денег.
