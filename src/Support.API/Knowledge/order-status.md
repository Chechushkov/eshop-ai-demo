# Статусы eShop
Submitted — заказ создан. AwaitingValidation — ожидается проверка.
StockConfirmed — наличие подтверждено. Paid — оплачен. Shipped — отправлен. Cancelled — отменён.
Статус читается из Ordering.API среди заказов текущего покупателя.
В этой версии eShop отдельного статуса delayed и поля дней задержки нет.
