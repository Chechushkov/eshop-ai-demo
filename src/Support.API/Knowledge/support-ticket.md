# Заявка поддержки
Заявка создаётся только по выбранному заказу текущего покупателя с его явным разрешением.
После успешной записи сервис возвращает номер T- и 32 шестнадцатеричных символа.
Повтор того же запроса с тем же requestId возвращает существующую заявку.
Учебная заявка хранится в таблице support_tickets базы knowledge и не отправляется во внешнюю службу.
