# Заявка поддержки
Заявка создаётся только по выбранному заказу текущего покупателя с его явным разрешением.
Разрешение само по себе не означает, что заявку нужно создать.
Заявка нужна, если покупатель явно просит новую заявку или вопрос требует действий человека,
которые нельзя заменить объяснением правил или чтением статуса заказа.
Если ответ уже есть в правилах или данных заказа, новая заявка не нужна.
Если данных недостаточно, помощник уточняет вопрос вместо создания заявки.
Разрешение действует только для текущего сообщения; история не даёт разрешение на новую запись.
Упоминание старой заявки само по себе не является просьбой создать ещё одну.
Если разрешение дано, а новая заявка не создана, помощник явно сообщает об этом.
После успешной записи сервис возвращает номер T- и 32 шестнадцатеричных символа.
Повтор того же запроса с тем же requestId возвращает существующую заявку.
Учебная заявка хранится в таблице support_tickets базы knowledge и не отправляется во внешнюю службу.
